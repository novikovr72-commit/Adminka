# Шаблоны отчетов

Раздел UI: **Конструктор отчетов → Настройка отчетов** (`/report-settings`).

Домен: `report_templates` / `ReportTemplateController` / `ReportTemplateService`.

## Назначение

CRUD шаблонов Excel-отчетов: основные настройки, SQL, макет (`report_info`), привязки к организациям и группам доступа, preview и выгрузка `.xlsx`.

## Карточка отчета

Вкладки:

| Вкладка | Назначение |
| --- | --- |
| Основные | код, название, версия, статус, method (`AUTO`/`HAND`), `numberDays`, имя/тип выходного файла |
| SQL | редактор SQL, валидация, просмотр полей/результата |
| Настройка шаблона | логотип, заголовок, шрифты, стартовая ячейка, поля колонок (`report_info`) |
| Просмотр отчета | preview Excel / полный экспорт |

## Таблица БД

`public.report_templates`:

- `id` (uuid)
- `code_report`, `name`, `version`, `status`
- `method` — `AUTO` или `HAND` (для `HAND` при execute обязателен `roleNames`)
- `number_days` — только из БД, снаружи не передаётся
- `output_file_name`, `output_file_type`
- `sql_query`
- `report_info` (jsonb) — макет Excel
- `report_logo` (bytea)
- `deleted`

Связанные сущности: организации шаблона, группы доступа, получатели.

## Основные API

Базовый префикс: `/api/admin` (alias `/api`).

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/report-templates` | список шаблонов |
| POST | `/report-template` | создание |
| PATCH | `/report-template/{id}` | основные настройки |
| DELETE | `/report-template/{id}` | удаление (soft) |
| POST | `/report-template/sql/validate` | проверка SQL |
| POST | `/report-template/sql/execute-check` | execute-check SQL |
| POST | `/report-template/sql/results` | поля/результат SQL |
| PATCH | `/report-template/{id}/sql` | сохранение SQL |
| GET/PATCH | `/report-template/{id}/template-settings` | настройки макета |
| POST | `/report-template/execute` | формирование Excel (интеграционный) |
| POST | `/report-template/excel-preview` | preview |
| POST | `/report-template/excel` | полный Excel |
| POST/DELETE | `/report-template/{id}/organizations` | организации |
| POST/DELETE | `/report-template/{id}/access-groups` | группы доступа |

Для большинства путей есть alias во множественном числе: `/report-templates/...`.

## Интеграция экспорта

Внешний модуль вызывает:

`POST /api/admin/report-template/execute`

Минимальный body:

```json
{
  "reportTemplateId": "uuid",
  "reportId": "uuid",
  "startReport": "YYYY-MM-DD",
  "endReport": "YYYY-MM-DD",
  "claimOrganizationId": "uuid",
  "roleNames": ["role1"],
  "preview": false
}
```

Подробности: `adminka/REPORT_EXPORT_INTEGRATION_GUIDE.md`, `adminka/REPORT_EXPORT_EMBED_GUIDE.md`, OpenAPI — `adminka/docs/api/openapi-report-export.json`.

## Слои backend

- `controller/ReportTemplateController` — HTTP
- `service/ReportTemplateService` — CRUD и настройки
- `service/ReportTemplateSqlService` + `ReportTemplateSqlCore` — SQL
- `service/ReportTemplateExecuteService` + `ReportTemplateExcelFacade` / `ReportTemplateExcelCore` — Excel
- `repository/ReportTemplateRepository` — SQL к БД

## Типовой сценарий

1. Создать шаблон (код, название, method, version).
2. Ввести и провалидировать SQL.
3. Настроить макет (логотип, заголовок, поля).
4. Привязать организации / группы доступа.
5. Проверить preview → сохранить → вызвать execute из внешнего модуля.
